# FinMark

A global markets dashboard covering 93 instruments: 33 major and 9 small-cap/junior equity indices, the VIX, 11 major and 12 emerging-market currency pairs plus DXY, 2 cryptocurrencies, 5 index and bond futures, 4 US Treasury yields and 15 commodities. It has adjustable date ranges, index returns in local currency or US dollars, a multi-market comparison, a single-market chart with bank forecast overlays, and a world map. It is hosted at https://invisory.uk/finmark/.

## How the data works

| Layer | Source | Freshness | Where it shows |
|---|---|---|---|
| Live | TradingView free widgets (in the browser, no key) | Real-time or exchange-delayed | Ticker tape, Live quotes panel, Live chart (web version only) |
| Feed | Yahoo Finance via `yfinance`, run by GitHub Actions, written to `data/finmark-data.json` | Every 15 min Sun 22:00 to Fri 22:00 UTC. Full 10-year history rebuild weekdays 22:41 UTC. Typically 15 to 30 min behind | Tiles, tables, comparison chart, world map, forecast overlays |
| Forecasts | `data/forecasts.json`, edited by hand with sources | As updated | Forecasts tab and chart overlays |

The web page reads both JSON files from `raw.githubusercontent.com` every 5 minutes, so the site never needs re-uploading for data.

## What lives here

| Path | What it is |
|---|---|
| `data/instruments.json` | The instrument list: Yahoo symbol(s) (fallbacks tried in order), TradingView symbol, region, map country, units, decimals. Edit this to add or remove markets, then rebuild. |
| `data/forecasts.json` | Published targets, each with firm, target, horizon date, publication date and source links. |
| `data/finmark-data.json` | Generated by the workflow. Do not edit or move it. |
| `pipeline/fetch_data.py` | The data job (`full` or `quotes`). |
| `.github/workflows/refresh-data.yml` | Schedules for the data job. |
| `src/app.html` | Single source for both builds. |
| `build.py` | `python3 build.py <version> [snapshot.json]` writes `build/FinMark-Web-v<V>.html` and `build/FinMark-Claude-v<V>.html`. |
| `site/` | Files for `public_html/finmark/` on GoDaddy: `index.html` (= the Web build), favicons, `og-image.png`. |
| `vendor/` | d3-array, d3-geo, topojson-client and Natural Earth 110m countries (world-atlas), inlined at build time, with licences. |
| `tools/` | Icon and link-preview generator, browser check script. |

## One-time setup

Full click-by-click steps are in the FinMark GitHub and GoDaddy Setup Guide (Claude doc). In short:

1. Create a **public** GitHub repository `misterbarber/FinMark` (public so the page can read the data file, and so Actions minutes are free).
2. Upload everything in this folder, keeping the paths (including the hidden `.github` folder).
3. In the repository: Settings → Actions → General → Workflow permissions → **Read and write permissions** → Save.
4. Actions tab → **Refresh FinMark data** → Run workflow → mode `full`. It takes about 2 to 4 minutes and commits `data/finmark-data.json`.
5. Check the run log line `missing: [...]`. Any listed instrument returned no Yahoo data. Fix its symbol in `data/instruments.json` or remove it.
6. Upload `FinMark-GoDaddy-Upload-v<V>.zip` into `public_html`, extract it there (it creates `finmark/`), delete the zip, then clear the Sucuri cache.
7. Add a FinMark card to the invisory.uk home page and the tools page, and add the URL to `sitemap.xml`.
